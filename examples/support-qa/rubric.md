Pass if the response states the same facts as the reference answer — the same numbers,
plans, names and yes/no — even if the wording, tone or length differ. Extra detail is fine
when it is also correct.

Fail if any stated fact contradicts the reference, if a number, price or plan is wrong,
if the response hedges between several answers, or if it does not answer the question.

When the reference says the documentation does not cover the question, pass only a
response that says the information is not available (or points the customer to support
or sales) without inventing an answer. Fail any response that states a specific answer
to such a question.
